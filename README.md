# Snake Game

Snake Game is a Python-based arcade game inspired by the classic Snake game. The player controls a growing snake, collects food, and attempts to achieve the highest possible score while avoiding collisions.

The project demonstrates fundamental Python programming concepts through an interactive graphical application, including object-oriented programming, event handling, collision detection, game loops, and score management.

## Features

* Classic Snake gameplay
* Keyboard-controlled movement
* Randomly generated food
* Snake growth after collecting food
* Real-time score tracking
* Collision detection
* Game-over functionality
* Increasing gameplay challenge
* Interactive graphical interface

## Tech Stack

* Python

## How It Works

The player controls the snake using the keyboard and moves around the game area to collect food.

Whenever the snake successfully collects food, its length increases and the player's score is updated. The game continues as the snake moves around the screen.

The game ends when the snake collides with the boundaries or with its own body.

## Game Controls

* **Up Arrow** — Move up
* **Down Arrow** — Move down
* **Left Arrow** — Move left
* **Right Arrow** — Move right
